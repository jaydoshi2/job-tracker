## Job description

### What You Will Be Doing
Participate in different phases of the Software Test lifecycle in close collaboration with the development teams and Project Engineers to drive defects to closure.
- Develop and complete both automated and manual Test Plans/Test Cases with various test strategies: Functional, Negative, Regression, customer/end-user, Performance, Reliability and Usability testing
- Prioritize and handle several concurrent projects and testing tasks
- Reproduce, troubleshoot and triage software defects, report them and drive them to closure
- Build Test Cases/Plans for new features, new products (dGPU and APU) and new Operating Systems (Linux and/or Windows)
- Share ideas to improve current processes
- Identify metrics and measurements for various aspects of the software QA development cycle and make them efficient

  - Exposure to development/triaging/debugging in Linux and/or Windows
