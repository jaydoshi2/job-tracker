## Job description

Kensho is S&P Global's hub for AI innovation: ML, NLP, data discovery, generative AI applications, agents, data retrieval APIs, data extraction (Kensho Extract), speech recognition, entity linking, text classification.

ML Engineer interns join the team building a GenAI platform, LLM-powered applications, and AI toolkit solutions.

### What You'll Do
- Solve challenges in agentic design and LLM orchestration: context engineering, data access patterns, memory management, and evaluation of agent performance
- Lead a project to prototype, build, and test ML models and pipeline components under senior engineers
- Work across the ML model lifecycle: problem framing, model selection, pipeline development, evaluation, deployment support
- Work in a cross-functional team of ML Engineers, PMs, Designers, and Full-Stack Engineers

### What You'll Need
- Pursuing a bachelor's or higher with ML classwork or internships
- Experience designing and iterating on agentic systems and evaluating agent performance
- Experience with advanced machine learning methods
- Statistical knowledge and experience modeling real data
- Expertise in Python and Python-based ML frameworks (LangGraph, Pydantic AI, PyTorch)
- Effective coding, documentation, and communication habits

### Technologies & Tools
- **Agentic systems:** agentic orchestration, deep research, information retrieval, semantic search, LLM code generation, LLM tool use, textual RAG
- **Core ML/AI:** LangGraph, Transformers, HuggingFace, LightGBM, PyTorch, SKLearn, XGBoost
- **Data exploration:** Jupyter, Matplotlib, Pandas, Weights & Biases, Langfuse
- **Data management:** Apache Spark, AWS Athena, DVC, LabelBox, OpenSearch, Postgres/Pgvector, S3, SQLite
- **Deployment & MLOps:** Arize, Airflow, AWS, DeepSpeed, Docker, Grafana, Jenkins, LangFuse, LiteLLM, Ray, vLLM
- **Prototyping:** Claude Code, FastAPI, Streamlit, Gradio
